# Analizador, Miner y visualizer Ciberseguridad

## Como ejecutar
- Clonar repositorio
- Construir el contenedor ingresar esto en la consola:
     `docker build -t miner-fran .`
- Encender el contenedor ingresar esto en consolar:
    `docker run -p 8080:8080 miner-fran`
- Mediante algun gestor visual de archivos, realzar doble click sobre el index.html

- Para apagar y eliminar el contenedor ingresar esto en consola:
    `docker rm -f miner-fran`
